# UI 设计规范

> 方向来源：Tavo 自带 Arcana 主题（深色沉浸）+ unslop 设计纪律。
> 目标：一个"安静的深夜对话空间"——chrome 退到背景，内容与角色是唯一的主角。

## 方向（Direction）

- **Product**：本地运行的 AI 角色对话工具，让人与自建角色持续交谈，并管理多个角色与会话
- **Character**：克制、沉浸、夜读感（restrained, after-dark, literary）
- **World**：深夜书桌上的一束暖光——深色墨面、纸张质感、文字发光
- **Moments**：角色消息气泡（流式打字时逐字出现的文字 + 说话人名 + 呼吸状态点）；角色卡上那道暖色主色条
- **Signature**：消息左侧的细竖线色条——当前说话角色的标识色，只出现在角色消息上

## 色彩（一套中性 ramp + 一个强调色）

来自 Arcana 主题实测值，经 unslop 收敛：

| 用途 | 值 | 说明 |
|---|---|---|
| 页面背景 | `#121214` | 中性墨黑，非纯黑，来自主题 `#111111` 微调 |
| 表面（卡片/输入区） | `#1B1B1E` | 一次 surface step |
| 表面 elevated | `#242428` | 二次 step（抽屉、弹层） |
| 边框 | `rgba(255,255,255,0.08)` | 发丝线 |
| 主文字 | `#EDEDEF` | 来自主题 `#FFF2F2F2` |
| 次文字 | `#A6A6AD` | |
| 弱文字 | `#6E6E76` | meta、时间 |
| 强调色 | `#E0B872` | 暖琥珀，来自主题引用色 `#F1CC60` 降饱和 |
| 强调色文字态 | `#E9C98E` | 在深色背景上达到对比度 |
| 语义-错误 | `#D98A7A` | 收敛的暖红 |
| 语义-成功 | `#7FB08A` | 收敛的灰绿 |

**禁止**：紫蓝渐变、发光阴影、渐变文字、彩色背景大色块、emoji 当图标。

## 间距（4px 网格）

- 页面边缘：手机 16px，桌面 24px
- 卡片内边距：16px（手机）/ 20px（桌面）
- 消息之间的间距：16px；同一角色连续消息 8px
- 输入区高度：紧凑 48px，展开（多行）自增高，最大 120px
- 列表行高：44px（触控友好），行间距 4px
- 导航（底部 tab）高度：56px + 安全区
- 分组间距：组间 24px，组内 8px

## 字体与字号

- 界面字体栈：`-apple-system, "SF Pro Text", "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 正文字号：15px / 行高 1.65（对话正文，接近主题 15.33px）
- 标题：17px / 500
- 页面主标题：22px / 500
- meta、标签：12px / 400，弱色
- 字重只用 400 / 500；标题不超 600
- 数字用 `font-variant-numeric: tabular-nums`

## 图标

- 统一使用内联 SVG 线性图标，尺寸 18px，描边 1.5px
- 图标颜色继承文字角色（次要/弱），不单独着色
- 图标盒子宽度一致，与文字间距 8px
- 禁止 emoji 当图标；角色头像用「首字 + 角色标识色」生成，不用 emoji

## 圆角与细节

- 按钮：8px；输入区：12px；卡片：14px；弹层：18px
- 嵌套圆角：内层 = 外层 - padding（如卡片 14px、内衬 10px）
- 边框一律发丝线 `rgba(255,255,255,.08)`
- 键盘焦点：2px 强调色 rings（仅 focus-visible）

## 动效（只保留解释性的）

- 消息出现：150ms 淡入 + 上移 4px
- 抽屉：200ms `transform: translateX` + 遮罩淡入
- 弹层：160ms 淡入 + 缩放 0.98→1
- 按钮按下：`scale(0.98)` 80ms
- 流式打字：文字逐字追加（由数据驱动，非 CSS 动画）
- 状态点：仅"生成中"呼吸；其他地方禁止循环动画
- 统一 easing：`cubic-bezier(.2,.8,.2,1)`；时长只用 80/150/200ms

## 布局

- 手机（<720px）：单栏，底部 tab 导航，聊天页占满视口高度，输入框固定在底部（含 safe-area）
- 桌面（≥720px）：应用居中，最大宽度 1120px；左侧固定 264px 侧栏（角色列表导航），右侧聊天区；设置页为居中的表单卡片（最大 640px）
- 不把手机页面直接拉伸到桌面宽度；桌面端利用侧栏填充空间
- 安全区：`env(safe-area-inset-bottom)` 用于底部导航和输入区
