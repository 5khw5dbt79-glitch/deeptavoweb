# 页面结构与路由

## 1. 页面树（本复刻范围）

```
App
├── 聊天页 /#/chat              [主页面，默认]
│   ├── 会话头部（当前角色名、模型、状态点）
│   ├── 消息列表（用户气泡 / 角色气泡 / 状态提示）
│   ├── 输入区（附件按钮、文本域、发送/停止按钮）
│   └── 角色抽屉（从左侧滑出，角色列表 + 新建入口）
│
├── 角色页 /#/characters
│   ├── 角色卡片列表
│   ├── 角色编辑弹层（新建/编辑）
│   │   └── 字段：名称、一句话简介、系统提示词、开场白、头像色
│   └── 删除确认弹层
│
└── 设置页 /#/settings
    ├── API 配置：Base URL、API Key、模型名
    ├── 生成参数：温度、最大上下文消息数
    └── 数据管理：导出、清空
```

## 2. 路由表

| Hash 路由 | 页面 | 进入方式 | 返回 |
|---|---|---|---|
| `#/chat` | 聊天页 | 默认 / 底部导航 / 角色切换后 | — |
| `#/characters` | 角色页 | 底部导航 / 聊天页角色抽屉"管理角色" | 底部导航 |
| `#/settings` | 设置页 | 底部导航 / 聊天页头部设置入口 | 底部导航 |

- 采用 hash 路由，刷新后停留在当前页。
- 角色抽屉属于聊天页内的浮层，不改变路由。
- 角色编辑/删除确认属于角色页内弹层，不改变路由。

## 3. 页面关联

- **角色 → 聊天**：在角色页或抽屉中选中某角色 → 切换到该角色的会话 → 跳转聊天页。若无会话则先用"开场白"创建一条角色消息。
- **聊天 → 设置**：API 未配置时，点击发送会提示并跳转设置页。
- **设置 → 全部**：设置保存后全局生效（所有角色共用一套 DeepSeek 配置）。

## 4. 状态与恢复

- 当前激活角色 id、各角色会话消息、设置项均持久化到 localStorage。
- 刷新后：路由保持、当前角色保持、消息历史完整恢复、设置保持。
- API Key 保存在浏览器本地（localStorage），仅在用户主动请求时随 HTTPS 请求发往 DeepSeek；不做任何中继。
